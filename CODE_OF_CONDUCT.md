# Code of Conduct

We want project participation to be safe, constructive, and welcoming.
Contributors and maintainers must communicate respectfully, accept technical
critique in good faith, avoid harassment and discrimination, and protect other
people's private information and credentials.

Unacceptable behavior may be reported privately through the repository's
GitHub Security Advisory channel when privacy is needed, or to the repository
owner through their GitHub profile. Maintainers may edit, reject, or remove
contributions and participation that violate these expectations.

This compact policy applies to repository issues, pull requests, reviews, and
other spaces officially associated with the project.
